Privacy Policy — Agentic AI OS

Last updated: November 4, 2026

Agentic AI OS is a personal tool that runs only on its owner's computer. It has no other users.

What data is used

When the owner connects TikTok, the tool receives an access token, a refresh token, the account's open ID and display name, and the account's posting limits. It uses them only to upload and publish the owner's own videos.

Where it is stored

Tokens are stored only in a local file on the owner's computer. Nothing is sent to any server other than TikTok's official API. No data is sold, shared or used for advertising.

Deleting data

Disconnecting TikTok in the tool deletes the local token file. Access can also be withdrawn from the TikTok app: Settings and privacy → Security & permissions → Apps and services.
